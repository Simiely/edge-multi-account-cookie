# Edge Multi-Account Cookie Switcher

> 安全的 Edge 多账号 Cookie 切换器 — 本地存储、密码锁保护，一键切换网站账号，支持 WebDAV 远程备份。
>
> **版本：** v2.9.0 | **架构：** Manifest V3 | **主题：** 珊瑚粉深色 | **协议：** MIT

---

### 简介

一款基于 **Manifest V3** 的 Edge/Chrome 浏览器扩展，让你在同一浏览器中**保存和切换多个网站账号**，无需反复登录退出。

Cookie 值明文存储（与浏览器自身 Cookies 数据库一致，避免加密膨胀超限导致切换失效）、密码锁保护、WebDAV 远程备份、纯原生 JS 零第三方依赖。**珊瑚粉深色主题 UI**（主色 `#FF9292`），弹窗采用 Gmail 式身份锚点 + 账号卡片流，设置页采用分区卡片式 + 状态概览栏。

### 核心功能

| 功能 | 说明 |
|------|------|
| 🎨 **珊瑚粉主题** | 全新深色 UI（主色 `#FF9292`），弹窗身份锚点 + 账号卡片流，设置页分区卡片 + 状态栏 |
| 🔄 **一键切换** | 保存当前网站的 Cookie + localStorage，点击卡片即可切换到目标账号（popup 直调，兼容所有站点） |
| 💾 **保存账号** | 自动抓取当前登录状态的 Cookie（含 httpOnly、Partitioned Cookie、子域）和 localStorage 数据；**保存前自动去重，杜绝多套会话混存** |
| 🩺 **会话健康** | 切换后自动探测会话是否被服务端认可；失效账号卡片红点标记、右键菜单 ⚠ 提示；每日后台体检 |
| 🔐 **密码锁** | PBKDF2（60 万次迭代）验证 + 连续失败指数锁定；打开弹窗需输入密码 |
| 📦 **智能备份** | 有密码锁 → 导出/导入自动用锁密码加解密；无锁 → 弹窗输入口令；支持合并/覆盖模式 |
| ☁️ **WebDAV 备份** | 加密备份上传到 `workbuddy/网页账号管理/` 目录，URL 留空自动用默认服务器，支持定时备份与远端保留策略 |
| ⌨️ **快捷键** | `Alt+Shift+S` 快速打开弹窗 |
| 🖱️ **右键菜单** | 右键页面 → "清除此站点 Cookie" / "切换到此站点账号" |

### 权限说明

| 权限 | 用途 |
|------|------|
| `cookies` | 读写网站登录 Cookie |
| `storage` | 本地加密存储账号数据（local + session） |
| `tabs` / `activeTab` | 获取当前标签页的域名与状态 |
| `scripting` | 读写页面 localStorage |
| `contextMenus` | 右键菜单 |
| `alarms` | WebDAV 定时自动备份 |

扩展默认不申请任何网站权限，仅在点击弹窗时通过 `activeTab` 获得临时权限。WebDAV 服务器域名在配置时按需授权。

### 安装方法

1. 从 [Releases](https://github.com/Simiely/edge-multi-account-cookie/releases) 下载最新 ZIP
2. 解压到任意目录
3. 打开 Edge 浏览器，进入 `edge://extensions/`
4. 打开右上角的 **"开发人员模式"**
5. 点击 **"加载解压缩的扩展"**
6. 选择解压后的文件夹

### 使用方法

1. 登录你的网站账号
2. 按 `Alt+Shift+S` 打开扩展弹窗
3. 如果弹窗显示授权横幅，点击「授权访问此网站」
4. 输入账号名称，点击「保存账号」
5. 登录第二个账号，重复步骤 2-4
6. 之后在弹窗中点击账号卡片即可一键切换

> ⚠️ **注意**：切换账号时使用扩展的「切换到该账号」功能，不要使用网站自带的"退出登录"，否则已保存的 Cookie 会被服务器端作废。

### WebDAV 远程备份

1. 打开设置页 → 在「WebDAV 远程备份」卡片填写服务器 URL（**留空自动用默认服务器**）、用户名、密码
2. 点击「测试连接」验证（首次会自动请求该服务器的访问权限）
3. 点击「保存配置」→「立即备份」上传加密备份（存储于 `workbuddy/网页账号管理/` 目录，自动创建）
4. 可选：展开「高级选项」设置「自动备份」为每天/每周，扩展将定时在后台自动备份
5. 「下载恢复」从远端最新备份恢复数据（支持合并/覆盖模式）
6. 弹窗底部「📤 上传 / 📥 下载」图标可快捷备份，无需进设置页

> 备份文件为 AES-GCM 密文，口令即 WebDAV 密码——即使服务器管理员也无法读取你的账号数据。

### 常见问题

**Q: 保存了 0 个 Cookie？**
A: 未获得当前网站的访问权限。弹窗顶部会显示授权按钮，点击「授权访问此网站」即可。

**Q: 点击"登录新账号"后还是登录状态？**
A: 更新到最新版本即可。

**Q: 密码锁能干什么？**
A: 开启后打开弹窗需输入密码，连续输错 5 次会锁定一段时间；Cookie 数据本地明文存储（与浏览器自身一致），备份/导出环节仍加密保护。

**Q: 导出备份需要输入密码吗？**
A: 设置了密码锁 → 自动用密码锁密码加密（无需输入）；未设锁 → 弹窗输入任意口令。导入同理：先自动用锁密码尝试，失败再弹窗输入。

**Q: 重装扩展后密码和账号数据还在吗？**
A: manifest 中加入了 `key` 字段，扩展 ID 固定，重装后数据保留。

**Q: 旧版本（v2.2 及更早）数据会丢失吗？**
A: 不会。首次打开新版本会自动迁移：既有 Cookie 自动加密、密码锁自动升级为更强的 PBKDF2 格式；旧备份文件导入时自动兼容旧迭代次数（10 万次）解密。

**Q: 账号卡片上的绿点/红点是什么意思？**
A: 会话健康状态：绿点 = 最近探测会话有效；红点 = 服务端已不认可该会话（如登录过期/被登出），建议重新登录后覆盖保存。每日自动体检，切换时也会实时探测。

**Q: 切换后提示"服务端判定会话已失效"？**
A: 说明该账号保存的 Cookie 虽然未过期，但服务端会话已被清理（SSO 会话过期、异地登出等）。重新登录该账号，再点「保存账号」覆盖即可。

**Q: WebDAV 保存后点「连接测试」还要输入密码？**
A: 不需要。已保存的配置会记住凭据，密码框留空时点「连接测试」会自动复用已保存的用户名/密码。仅当从未保存过配置时才需填写。
